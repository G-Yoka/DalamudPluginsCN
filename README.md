# G-Yoka Dalamud 国服插件库

面向国服 Dalamud 的第三方插件仓库。

## 添加插件仓库

在 Dalamud 设置的“第三方插件”页面添加以下地址：

```text
https://raw.githubusercontent.com/G-Yoka/DalamudPluginsCN/main/pluginmaster.json
```

保存并刷新插件安装器后，即可搜索、安装和更新本仓库中的插件。
