# 更新记录

## 0.2.0（待发布）

### 新增

- 新增自动事件与战斗接管流程（测试）：按参与范围和优先级选择 FATE／CE，自动导航、下坐骑、选择事件目标，并连接 BossmodRebornCN、AEAssistV3、PromeRotation 或 Rotation Solver Reborn。（目前仅测试 BossmodRebornCN + AEAssistV3 组合）
- 新增 39 条内置 FATE／CE 基础路线，覆盖当前已录制的南部 18 条、北部 21 条路线；内置路线用于缺省回退，推荐用户按自己的移动环境重新录制。（未完全覆盖）
- 新增完整路线录制与回放，记录从水晶传送落点到事件终点的路线，并支持保存和执行玩家主动跳跃。
- 新增手动导航与自动事件分别启用录制路线的开关。
- 新增完整配置 JSON 导入导出，包含用户设置、录制路线和校准数据；导入前自动备份当前配置。
- 新增“路线”详情页，显示导航状态、路线决策和地图路径。

### 改进

- 导航会比较直达、亚返回、步行至水晶和水晶传送的预计用时，并学习本机传送、上坐骑和下坐骑耗时。
- 南北岛导航均可绕开高等级敌对生物的警戒范围。
- 自定义路线中断后会从当前位置裁剪已走路径并继续执行，减少 vnavmesh 短暂停止导致的卡住。
- 魔法罐寻宝候选在角色死亡、罐子消失后正确重置。

### 修复

- 修复 vnavmesh 已就绪但路径规划停滞、状态快速切换造成卡顿的问题。
- 修复北岛水晶传送索引错误、亚返回程接近水晶时反复停走的问题。
- 修复地图高低层坐标解析可能导航到错误楼层的问题。
- 修复其他诸多内容。
