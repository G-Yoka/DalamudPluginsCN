# 更新记录

## 0.2.0.3 测试版（2026-10-01）

### 新增

- 自动事件与战斗接管（测试）新增 BossMod 危险区安全余量设置，可选择使用 BossMod 当前值或临时应用 0.5、1.5、3.0 米。
- 新增 BossMod 移动决策延迟设置，可选择使用 BossMod 当前值或临时应用 0、0.10、0.25、0.50 秒；接管结束后恢复原值。

### 改进

- 魔法罐报告发现财宝后立即停止导航并下坐骑，只在发现提示后关联附近新出现的宝箱。
- 宝箱交互改为单次发送并等待开启、淡出或消失确认，避免重复交互重置开箱读条。
- 普通野外宝箱改为结合实际宝箱类型识别，减少误关联和候选点误校准。

### 修复

- 修复自动寻宝抵达魔法罐宝箱附近后不下坐骑、没有发送开箱交互的问题。
- 修复他人施放复活后，部分复活确认窗口无法自动接受的问题。

## 0.2.0.2 测试版（2026-10-01）

### 新增

- 北岛 FATE／CE 现在显示带颜色的 `[α]`、`[β]`、`[γ]` 消幻晶标签；自动事件会读取背包数量，优先选择当前数量最少的消幻晶类型。
- 魔法罐候选点校准现在会记录北岛地图层，并只在对应地图层显示和选择候选点。

### 改进

- 自动事件与战斗接管（测试）会为支持的事件建立 BossmodRebornCN 专用追击预设。罗盘负责锁定有效目标和下坐骑，BossMod 统一负责追进攻击距离与机制移动，战斗中不再使用 vnavmesh 补位。
- 自动开启 BossMod 的目标追击、战斗追击和机制模块期间追击；事件结束后关闭 BossMod AI 并恢复此前预设。
- 暂停、停止或重新启用自动流程时，可以直接接管角色已经进入或正在等待的 CE；刚完成的事件会短暂忽略，避免再次被选择。
- 校准后的魔法罐候选使用记录的真实高度导航，减少北岛高低层选错导航网格。

### 修复

- 将“撒娇罐”加入强制目标黑名单，避免自动战斗错误锁定该单位。
- 修复事件结束后没有正确亚返回，或因残留移动输入立即取消返回的问题；亚返回未完成时会重试，持续失败后才改为步行水晶。
- 修复位于总部水晶附近的自定义等待点被视为普通远程等待点，导致打完事件后骑乘走回等待点的问题。
- 修复北岛二层魔法罐候选在一层地图显示，以及可能导航到同一平面坐标的错误楼层的问题。

## 0.2.0.1 测试版（2026-09-29）

### 新增

- 新增单条路线 JSON 导入与导出，可分享某一条内置或用户路线；导入后会作为新的用户路线保存。
- 新增自动接受他人复活并恢复战斗流程；复活后会重新接管角色当前正在参与的 CE／FATE。
- 新增事件目标优先表接口，为后续需要优先击杀特定小怪的事件预留配置入口。

### 改进

- 自动事件与战斗接管（测试）在暂停或停止后重新启动时，会优先恢复角色当前正在参与的 CE／FATE。
- 仅在当前事件存在 BossmodRebornCN 机制模块时，才交由 BossmodRebornCN 接管机制移动和目标优先级；没有对应模块时继续由新月罗盘索敌。
- 内置路线与用户路线列表重新调整列宽和按钮间距，并自动清理与内置路线完全相同的旧用户路线副本。

### 修复

- 修复亚凡回已成功抵达营地后，自动流程仍因等待点距离判断而错误暂停的问题。

## 0.2.0（2026-09-19）

### 新增

- 新增自动事件与战斗接管流程（测试）：按参与范围和优先级选择 FATE／CE，自动导航、下坐骑、选择事件目标，并连接 BossmodRebornCN、AEAssistV3、PromeRotation 或 Rotation Solver Reborn。（目前仅测试 BossmodRebornCN + AEAssistV3 组合）
- 新增 39 条内置 FATE／CE 基础路线，覆盖当前已录制的南部 18 条、北部 21 条路线；内置路线用于缺省回退，推荐用户按自己的移动环境重新录制。（未完全覆盖）
- 新增完整路线录制与回放，记录从水晶传送落点到事件终点的路线，并支持保存和执行玩家主动跳跃。
- 新增手动导航与自动事件分别启用录制路线的开关。
- 新增完整配置 JSON 导入导出，包含用户设置、录制路线和校准数据；导入前自动备份当前配置。
- 新增“路线”详情页，显示导航状态、路线决策和地图路径。

### 改进

- 导航会比较直达、亚返回、步行至水晶和水晶传送的预计用时，并学习本机传送、上坐骑和下坐骑耗时。
- 南北岛导航均可绕开高等级敌对生物的警戒范围。
- 自定义路线中断后会从当前位置裁剪已走路径并继续执行，减少 vnavmesh 短暂停止导致的卡住。
- 魔法罐寻宝候选在角色死亡、罐子消失后正确重置。

### 修复

- 修复 vnavmesh 已就绪但路径规划停滞、状态快速切换造成卡顿的问题。
- 修复北岛水晶传送索引错误、亚返回程接近水晶时反复停走的问题。
- 修复地图高低层坐标解析可能导航到错误楼层的问题。
- 修复其他诸多内容。
