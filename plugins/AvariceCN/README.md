# Avarice 简中版

基于 [PunishXIV/Avarice](https://github.com/PunishXIV/Avarice) 正式版 `2.2.0.14` 制作的非官方简体中文版本，适配国服 Dalamud API 15。

## 安装

在 Dalamud 设置的“第三方插件”页面添加：

```text
https://raw.githubusercontent.com/G-Yoka/DalamudPluginsCN/main/pluginmaster.json
```

保存并刷新插件安装器，搜索 `Avarice 简中版` 安装即可。

本插件的内部名称为 `AvariceCN`，不会被上游英文版的更新文件覆盖。由于两者会注册相同命令和 IPC，请勿与英文版 Avarice 同时启用；安装前应先卸载或禁用英文版。

## 汉化范围

- 设置窗口、选项、帮助提示与显示条件
- 配置方案、职业名称与任务名称
- 身位统计、战斗汇总与聊天反馈
- Splatoon 联动、场地中心与调试界面

Wrath Combo、Rotation Solver、Splatoon、Pictomancy、IPC 等产品名和技术缩写保持原文。
